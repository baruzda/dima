# UX Audit

## Процесс

1. Зафиксируй пользователя, JTBD и ожидаемый outcome.
2. Пройди сценарий от реальной точки входа до результата.
3. Для каждого шага оцени:
   - понятно ли текущее состояние;
   - ясно ли основное действие;
   - есть ли лишнее решение или ввод;
   - сохраняется ли контекст;
   - понятно ли, что произошло после действия;
   - есть ли выход из ошибки;
   - корректна ли терминология;
   - доступен ли сценарий клавиатурой/assistive tech, где релевантно.
4. Проверь happy path, error path, empty/loading и возврат назад.
5. Отделяй дефекты от гипотез и вкусовых предпочтений.
6. Приоритизируй findings по влиянию на завершение задачи.
7. Для каждого finding предложи минимальное изменение и способ проверки.
8. Не меняй UI и код в этом проходе.

## Результат

```markdown
## User/JTBD
## Flow audited
## P0/P1 findings
## P2 findings
## P3 opportunities
## Evidence
## Recommended experiments
## Verdict
```

## Готово, когда

Каждый существенный finding связан с конкретной пользовательской проблемой и имеет проверяемую рекомендацию.
