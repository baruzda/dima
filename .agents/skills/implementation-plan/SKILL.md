# Implementation Plan

## Ограничение

Этот навык read-only. Не меняй код и конфигурацию.

## Процесс

1. Проверь `git status`, ветку и неизвестные изменения.
2. Найди команды install, dev, test, lint, typecheck и build.
3. Проследи фактический execution path.
4. Определи:
   - точки входа;
   - затрагиваемые модули;
   - контракты API и данных;
   - состояние и side effects;
   - существующие тесты;
   - документацию.
5. Сопоставь требования с конкретными файлами и символами.
6. Выбери минимальную архитектуру изменения.
7. Опиши риски, миграции, rollback и совместимость.
8. Составь порядок шагов так, чтобы каждый шаг был проверяемым.
9. Для каждого шага укажи проверку.
10. Отдели обязательное от возможного улучшения.

## Формат результата

```markdown
## Цель и границы
## Текущее устройство
## Затрагиваемые файлы и контракты
## Пошаговый план
## Проверки
## Риски и rollback
## Не входит в задачу
```

## Готово, когда

Implementation-агент может выполнить план без повторного широкого исследования и без выхода за scope.
