# UI Specification

## Вход

- утверждённый UX-flow;
- существующая дизайн-система или визуальные референсы;
- платформы и размеры экранов;
- технические ограничения.

## Процесс

1. Определи визуальный приоритет информации и действий.
2. Используй существующие токены и компоненты; новые вводи только при доказанном пробеле.
3. Для каждого экрана опиши:
   - структуру;
   - сетку и контейнеры;
   - типографическую иерархию;
   - компоненты;
   - состояния;
   - тексты;
   - поведение при взаимодействии.
4. Для каждого интерактивного компонента укажи:
   - default;
   - hover;
   - focus;
   - active;
   - disabled;
   - loading;
   - error;
   - selected, если релевантно.
5. Опиши responsive-поведение и критические breakpoints.
6. Проверь длинные тексты, переполнение, локализацию и системный масштаб.
7. Проверь контраст, клавиатурный фокус, labels и touch targets.
8. Укажи допустимую анимацию только там, где она объясняет переход или состояние.
9. Подготовь визуальные критерии проверки и размеры контрольных скриншотов.

## Результат

- спецификация экранов;
- инвентарь компонентов;
- список токенов;
- таблица состояний;
- responsive-правила;
- accessibility checklist;
- визуальный acceptance checklist.

## Готово, когда

Интерфейс можно реализовать без додумывания ключевых состояний и визуальных правил.
